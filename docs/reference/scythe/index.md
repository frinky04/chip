# What is Scythe?

Scythe is a plugin for game devs wanting to make levels directly in Unreal Engine's Editor for their games. Since the industry moved away from brush based level design, we lost something when we moved to static meshes: good level design tools. Scythe at its core is making static meshes feel as easy to work with as brushes, which is a huge challenge.

I share the opinion that Valve has solved the modern level design problems with their level design tool, Source 2 Hammer. I think Source 2 Hammer is the gold standard for modern level design tools, and Scythe is my attempt to bring Source 2 Hammer features to Unreal Editor.

It’s not just a blockout tool, it’s a full-fledged level editor designed so you don’t need Blender/Maya for your level creation.

Scythe is Unreal Engine's modeling tools rebuilt with level design and UX in mind with a lot of extra texture/UV features.

🔹 General Rule: If it’s in Source 2 Hammer, I’ll attempt to implement it.
